# Games Hub

A collection of HTML/JavaScript games created and published by me under the Game Noodles brand.

## About

This repository stores browser-based games that can be played directly in a web browser. Each game is built with web technologies such as HTML, CSS, and JavaScript.

## Playing the Games

Open a game's HTML file in a web browser, or visit the published game through its hosting link.

## Repository Contents

Each game is kept in its own folder with the files needed to run it, such as:

- `index.html`
- Images and other assets
